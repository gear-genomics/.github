## GEAR Genomics: a user-friendly, open-source web platform enabling interactive genomic analysis for molecular biologists

GEAR, [https://www.gear-genomics.com/](https://www.gear-genomics.com/), is a unified, web-based genomics framework that provides a collection of lightweight, interactive applications for common molecular biology and genomics analyses directly in the browser. All code is free and open-source.
